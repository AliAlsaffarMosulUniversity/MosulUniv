# تطبيق جامعة الموصل

تطبيق للهاتف يعمل على أندرويد والآيفون.
يعرض أخبار الجامعة ونشاطات الكليات والمراكز أسبوعياً.
البيانات تأتي مباشرة من الموقع الرسمي uomosul.edu.iq.

## الملفات

| الملف | وظيفته |
|---|---|
| index.html | واجهة التطبيق |
| styles.css | الألوان والتصميم |
| app.js | جلب النشاطات وتصنيفها وعرضها |
| data.js | قائمة الكليات والمراكز والخدمات، ونسخة محفوظة من الأخبار |
| manifest.webmanifest | بيانات التثبيت على الهاتف |
| sw.js | العمل بدون إنترنت |
| icons/ | أيقونات التطبيق |

## النشر على GitHub Pages

1. ارفع كل الملفات إلى المستودع MosulUniv.
2. من المستودع افتح Settings ثم Pages.
3. في Source اختر Deploy from a branch.
4. اختر الفرع main والمجلد / (root) ثم Save.
5. بعد دقيقة يصبح الرابط:
   https://alialsaffarmosuluniversity.github.io/MosulUniv/

## التثبيت على الهاتف

- أندرويد: افتح الرابط في Chrome ثم القائمة ثم "إضافة إلى الشاشة الرئيسية".
- آيفون: افتح الرابط في Safari ثم زر المشاركة ثم "إضافة إلى الشاشة الرئيسية".
- ملف APK لأندرويد: ضع الرابط في https://www.pwabuilder.com

## التعديل

- لإضافة كلية أو مركز: أضف سطراً في UNITS داخل data.js.
- لتعديل كلمات تصنيف النشاطات: عدّل TYPES داخل data.js.
- لتغيير نص الإهداء: عدّل ded1 وded2 وded3 داخل app.js.
- النصوص الإنجليزية: داخل STR.en في app.js، وأسماء الجهات داخل EN في data.js.
- بعد أي تعديل: غيّر رقم VERSION في sw.js حتى تصل التحديثات للهواتف.
